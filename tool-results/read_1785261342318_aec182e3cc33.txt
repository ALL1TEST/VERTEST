    22→## 1. Colors
    23→
    24→### Design Philosophy
    25→
    26→This palette is built on **accessibility-first** principles (WCAG AA compliance), with **semantic naming** for maintainability, and **CSS custom properties** for easy theming.

   270→### Color Usage Reference
   271→
   272→| Token | Usage | Example |
   273→|-------|-------|---------|
   274→| `--bg-primary` | Page background | `<body>` |
   275→| `--bg-secondary` | Cards, sidebars | `<article>`, `<aside>` |
   276→| `--bg-tertiary` | Code blocks, hover rows | `<pre>`, table hover |
   277→| `--text-primary` | Body text, headings | `<p>`, `<h1-h6>` |
   278→| `--text-secondary` | Metadata, captions | Date, author name |
   279→| `--text-tertiary` | Disabled, placeholder | `::placeholder` |
   280→| `--text-link` | Links | `<a>` |
   281→| `--border-default` | Input borders, dividers | `<input>`, `<hr>` |
   282→| `--border-focus` | Focus rings | `:focus-visible` |
   283→| `--interactive-primary` | Primary buttons | `.btn-primary` |
   284→| `--interactive-danger` | Delete, error actions | `.btn-danger` |
   285→
   286→### Contrast Ratios (Verified)
   287→
   288→| Combination | Ratio | WCAG Level |
   289→|-------------|-------|------------|
   290→| `--text-primary` on `--bg-primary` | 15.2:1 | AAA ✓ |
   291→| `--text-secondary` on `--bg-primary` | 4.8:1 | AA ✓ |
   292→| `--text-link` on `--bg-primary` | 4.7:1 | AA ✓ |
   293→| `--text-on-primary` on `--primary-600` | 4.6:1 | AA ✓ |
   294→| `--text-primary` on `--primary-50` | 4.8:1 | AA ✓ |
   295→| `--text-error` on `--error-bg` | 5.1:1 | AA ✓ |

   301→### Font Families
   302→
   303→```css
   304→:root {
   305→  /* ============================================
   306→     FONT FAMILIES
   307→     ============================================ */
   308→  
   309→  /* Primary - Body Text (Inter) */
   310→  /* Chosen for: Excellent screen readability, 
   311→     tall x-height, wide language support */
   312→  --font-sans: 'Inter', -apple-system, BlinkMacSystemFont, 
   313→              'Segoe UI', Roboto, 'Helvetica Neue', Arial, 
   314→              sans-serif;
   315→  
   316→  /* Secondary - Headings (DM Serif Display) */
   317→  /* Chosen for: Editorial feel, distinctive but readable,
   318→     pairs beautifully with Inter */
   319→  --font-serif: 'DM Serif Display', Georgia, 'Times New Roman', serif;
   320→  
   321→  /* Monospace - Code (JetBrains Mono) */
   322→  /* Chosen for: Ligatures, clear distinctions,
   323→     designed specifically for code */
   324→  --font-mono: 'JetBrains Mono', 'Fira Code', 'Cascadia Code', 
   325→              'Consolas', monospace;
   326→}
   327→
   328→/* Google Fonts Import */
   329→@import url('https://fonts.googleapis.com/css2?family=DM+Serif+Display:ital@0;1&family=Inter:wght@400;500;600;700;800&family=JetBrains+Mono:wght@400;500&display=swap');
   330→```
